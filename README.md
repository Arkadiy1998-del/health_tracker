Health Tracker - интерактивное веб-приложение для отслеживания показателей здоровья и самочувствия, реализованный на базе Streamlit

Проект предназначен для сбора данных пользователей (вес, сон, настроение, физическая активность) на ежедневной основе с последующем хранении в облачном DWH на PostgreSQL

На текущий момент (01.04.26) проект находится на стадии сбора данных для обучения ML моделей прогнозирования показателей здоровья и рекомендаций на основе машинного обучения

Функционал:

1. Ввод метрик
  - Пользователь выбирает дату и вводит показатели:
      - Вес
      - Часы сна
      - Настроение
      - Физическая активность
  - Проверка существования данных с возможностью перезаписи через интерактивный интерфейс
2. Сохранение данных
  - Данные сохраняются в облачный PostgreSQL с использованием UPSERT (ON CONFLICT DO UPDATE)
  - Метрики хранятся в отдельных столбцах, что упрощает дальнейшую обработку
3. Раздел "Помощь" в нижней части страницы с инструкцией и контактами разработчика

4. Интерфейс
  - Динамически адаптивный UI на базе Streamlit
  - Дизайнерское оформление страницы
  - Управление состоянием через st.session_state для предотвращения дублирования и сохраненения temp data
